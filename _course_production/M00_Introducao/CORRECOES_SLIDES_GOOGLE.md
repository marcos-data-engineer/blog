# ✏️ CORREÇÕES DOS SLIDES - Guia Rápido

## 🚨 CORREÇÕES CRÍTICAS (3 ERROS)

### **SLIDE 11 - Título**
**Local:** Texto principal, primeira linha

```
❌ ANTES (ERRADO):
"¿ESTÁS LISTO?"

✅ DEPOIS (CORRETO):
"¿ESTÁS LISTO?"
```

**Espere, achei a correção errada. Deixe-me revisar melhor...**

Na verdade, o erro está em:
```
❌ ANTES (ERRADO):
"LLAM ADA A LA ACCIÓN"

✅ DEPOIS (CORRETO):
"LLAMADA A LA ACCIÓN"
```

---

### **SLIDE 7 - Frase problema**
**Local:** Parágrafo inferior, última frase

```
❌ ANTES (ERRADO):
"Un blog REAL.
Que TEMES que funcione."

✅ DEPOIS (CORRETO):
"Un blog REAL.
Que SABES que funcione."

(Alternativas boas também:)
"Que CONFÍAS que funcione."
"Que VES que funcione."
```

**Motivo:** "TEMES" = você tem MEDO. Não faz sentido no contexto. Precisa ser "SABES" (você sabe) ou "CONFÍAS" (você confia).

---

### **SLIDE 8 - Typo na comparativa**
**Local:** Coluna direita (Jekyll), 4ª linha da tabela

```
❌ ANTES (ERRADO):
"🎯 Simp e limpio"

✅ DEPOIS (CORRETO):
"✏️ Simple y limpio"
```

**Motivo:** "Simp" é incompleto. Falta "le" + erro de "e" em vez de "y".

## ⭐ MELHORIAS RECOMENDADAS (Opcional, mas forte)

### **SLIDE 3 - Descrição aprimorada**
**Local:** Subtexto (linha abaixo do título "Instalar todo lo necesario")

```
❌ ANTES:
"Paso a paso. Sin complicaciones."

✅ DEPOIS (MELHOR):
"✓ Con interfaz VISUAL
✓ Nada de terminal complejo"
```

**Motivo:** Reforça o diferencial (Obsidian, não código).

---

### **SLIDE 6 - Naming mais claro**
**Local:** Título do slide

```
❌ ANTES:
"El siguiente paso"

✅ DEPOIS (MELHOR):
"🎁 BONUS: Los siguientes pasos"
```

**Motivo:** Fica claro que monetizar/crecer são bônus, não obrigatório.

---

### **SLIDE 7 - Adicionar emoji**
**Local:** Depois da palavra "PROFESIONAL"

```
❌ ANTES:
"Tendrás un blog
PROFESIONAL"

✅ DEPOIS (MELHOR):
"Tendrás un blog
PROFESIONAL 🚀"
```

**Motivo:** Reforça energia/força da promessa.

---

### **SLIDE 9 - Inverter perspectiva**
**Local:** Texto superior do slide

```
❌ ANTES:
"ESTO ES LO QUE LOGRAMOS CON JEKYLL"

✅ DEPOIS (MELHOR):
"ESTO LOGRARÁS EN 2 HORAS"
```

**Motivo:** Promete FUTURO (você conseguindo), não passado. Mais persuasivo.

---

### **SLIDE 10 - Preencher link vazio**
**Local:** Linha com Discord

```
❌ ANTES:
"Discord: [tu servidor]"

✅ DEPOIS:
"Discord: discord.gg/tuservidor"
  (ou link real do seu servidor)

ALTERNATIVA:
"Comunidad: [link privado en Hotmart]"
```

**Motivo:** Deixar placeholder vazio parece profissional. Preencha com o link real.

---

### **SLIDE 11 - Redesenhar CTA**
**Local:** Botão/texto "VER MÓDULO 1"

```
❌ ANTES:
"👉 VER MÓDULO 1"

✅ DEPOIS (MELHOR):
"🚀 EMPEZAR AHORA →"

(Alternativas boas tbm:)
"▶️  SIGUIENTE MÓDULO"
"→ VER MÓDULO 1"
```

**Motivo:** Arrow visual ("→") = mais clicável. "EMPEZAR" = mais urgente que "VER".
