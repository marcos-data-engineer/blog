2. O QUE FOI REALIZADO ATÉ AGORA (SESSÃO ATUAL)
-------------------------------------------------------------------------------

A) Refatoração Completa do Script Gerador (`scripts/generate_ai_post.py`):
   1. Parametrização via CLI (`argparse`):
      - `--title` / `-t`: Aceita título fixo ou gera dinamicamente se None.
      - `--keywords` / `-k`: Filtra feeds por termos específicos.
      - `--keywords ""` (modo autônomo): O Gemini lê as notícias brutas dos feeds,
        analisa tendências e escolhe autonomamente o melhor tema com justificativa.
      - `--model` / `-m`: Permite alternar entre `gemini-2.5-flash` e `gemini-2.5-pro`.
      - `--carousel`: Gera automaticamente a estrutura para carrossel em PDF (LinkedIn).
      - `--blog-only` / `--linkedin-only`: Gera apenas um dos artefatos.
      - `--dry-run`: Exibe os prompts sem consumir chamadas à API do Gemini.
   2. Resiliência e Correção de Bugs:
      - Timezone corrigido para `America/Sao_Paulo` (`-0300`).
      - Removidas importações não utilizadas (`urllib`, `json` soltos).
      - Tratamento de feeds malformados com `feedparser.bozo`.
      - Substituição de `print` por `logging` estruturado.
      - Validador pós-execução (Mermaid, Front Matter YAML, URLs de referências).
      - Salvamento do prompt utilizado em `_posts/.prompt-*.log` para rastreabilidade.

B) Criação da Estrutura de Carrossel para LinkedIn:
   - Suporte nativo à geração de carrosséis de 7 a 9 slides com limite de 40 palavras,
     foco em escaneabilidade, storytelling e CTA para engajamento.

C) Transição e Validação de Tema:
   - Mudança do tema genérico inicial para um título de alta conversão B2B:
     "O Fim do Hype da AGI: Por Que Sua Empresa Deveria Focar em Arquiteturas Híbridas"
   - O script foi executado e gerou três arquivos sincronizados em `_posts/`:
     1. `_posts/2026-10-22-o-fim-do-hype-da-agi-por-que-sua-empresa-deveria-focar-em-1531.md`
        (Artigo de blog com Mermaid de arquitetura n8n/Python/RAG/Ollama, tabela comparativa,
        citações acadêmicas reais e container preparado para vídeo do NotebookLM).
     2. `_posts/2026-10-22-linkedin-o-fim-do-hype-da-agi-por-que-sua-empresa-1531.txt`
        (Post de texto sem links no corpo para reter algoritmo, com 1º comentário estratégico).
     3. `_posts/2026-10-22-carousel-o-fim-do-hype-da-agi-por-que-sua-empresa-1531.txt`
        (Roteiro de 9 slides pronto para diagrama no Canva/Google Slides e exportação em PDF).

D) Criação do Prompt para NotebookLM:
   - Criado `scripts/prompt_gnote.txt` contendo as instruções para colar no caderno do
     NotebookLM para revisão crítica das fontes, roteiro do vídeo curto e geração de
     versão do artigo para exportação em PDF para revisão visual final.

3. GUIA DE EXECUÇÃO & COMANDOS (PARA O VSCODE / CLINE)
-------------------------------------------------------------------------------

Ambiente Python:
• Pacotes instalados no usuário (`~/.local/lib/python3.14/site-packages`):
  - `feedparser`
  - `google-genai`
• Chaves de API requeridas no terminal:
  export GEMINI_API_KEY="SUA_CHAVE_AQUI"
  # ou export GOOGLE_API_KEY="..."

Exemplos de execução do agente:

1. Gerar novo artigo com título definido e carrossel:
   python3 scripts/generate_ai_post.py \
     --title "Seu Título Aqui" \
     --carousel

2. Modo totalmente autônomo (descobre assunto do momento nos feeds):
   python3 scripts/generate_ai_post.py \
     --keywords "" \
     --carousel

3. Re-gerar apenas o LinkedIn com base no último artigo criado:
   python3 scripts/generate_ai_post.py \
     --linkedin-only \
     --carousel
